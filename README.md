# Rolling Game Zone

Rolling Game Zone es un e-commerce de hardware y periféricos orientado a gamers y usuarios de PC, con una experiencia visual moderna y funcional. La plataforma permite explorar productos, revisar detalles, realizar compras y, además, armar una PC a medida según las necesidades del cliente.

## Descripción del proyecto

La idea principal del proyecto es ofrecer una tienda online para la venta de hardware, accesorios y periféricos, con una interfaz atractiva y clara. Además de la navegación por productos, la web incluye funciones clave para una experiencia de compra completa, como:

- catálogos de productos por categoría
- detalle de cada producto
- carrito de compras
- login y registro de usuarios
- página de contacto
- sección acerca de nosotros
- footer informativo
- diseño responsive con Bootstrap

## Funcionalidades principales

## Stack tecnológico

El proyecto fue desarrollado con una estructura de frontend estático, utilizando Bootstrap 5.3 y 6.0 como base para el diseño responsive y componentes reutilizables. También se incorporaron librerías iconográficas y recursos visuales para mejorar la experiencia de usuario.


## Objetivo del proyecto

Crear una tienda online funcional y visualmente atractiva para la venta de hardware y periféricos, destacando la experiencia de compra, la presentación del catálogo y la posibilidad de personalizar la configuración de una PC.

## Cómo ejecutar el proyecto

1. Clonar el repositorio desde GitHub.
2. Abrir la carpeta del proyecto en tu editor preferido.
3. Ejecutar el archivo `index.html` o utilizar un servidor local para visualizar la web.

También puedes abrirlo directamente en el navegador o usar herramientas como Live Server para una vista más cómoda.
